# Quick Start Guide

## 🚀 Getting Started in 3 Steps

### 1. Open the Website
Simply open `index.html` in your web browser to see the portfolio in action.

### 2. Customize Your Content
Edit the following sections with your personal information:

#### Personal Details (All Pages)
- **Contact Info**: Update email, phone, location in `cv.html` and `contact.html`
- **Social Links**: Replace `#` with your actual URLs in all HTML files
  - LinkedIn: `https://linkedin.com/in/yourprofile`
  - GitHub: `https://github.com/yourusername`
  - Twitter: `https://twitter.com/yourusername`

#### CV Page (`cv.html`)
- Professional experience (job titles, companies, dates, responsibilities)
- Education history (degrees, universities, dates)
- Technical skills (names and proficiency levels)
- Certifications (names and issuing organizations)
- Key achievements

#### Projects Page (`projects.html`)
- Project titles and descriptions
- Technologies used
- Project categories for filtering
- Links to live projects or repositories

#### Home Page (`index.html`)
- Hero section text (your name and bio)
- Core competencies descriptions

### 3. Deploy Your Website
Choose one of these free hosting options:

#### Option A: GitHub Pages
1. Create a GitHub repository
2. Upload all files
3. Go to Settings → Pages
4. Select your branch and click Save
5. Access at: `https://yourusername.github.io/repository-name`

#### Option B: Netlify
1. Sign up at [netlify.com](https://netlify.com)
2. Drag and drop your folder
3. Your site is live instantly!

#### Option C: Vercel
1. Sign up at [vercel.com](https://vercel.com)
2. Import your repository or upload files
3. Deploy with one click

## 🎨 Customization Tips

### Change Colors
Edit `css/style.css` and modify these variables:
```css
:root {
    --accent-color: #33a3f3;  /* Change this to your preferred color */
}
```

### Modify Theme
The website automatically saves the user's theme preference (light/dark mode).

### Update Typing Animation
Edit `js/main.js` around line 373 to change the rotating text:
```javascript
this.texts = ['Your Text 1', 'Your Text 2', 'Your Text 3'];
```
